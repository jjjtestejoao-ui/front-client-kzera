# CLAUDE.md

## Regras de branch

Qualquer agente é proibido de criar branch, local ou remota. Branch só quem cria é o líder. Só criar com expressa autorização dele, repetida pelo solicitante para garantir que entendeu certo.

## Regras de commit

Não devo commitar sem autorização do líder. O stop hook vai alertar sobre arquivos não commitados, mas devo ignorar o aviso se já pedi ao líder para alterar isso e ele ainda não autorizou.
